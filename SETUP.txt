-------------------------------------------------------------------------------
 3. THE DAILY RUN ON GITHUB ACTIONS
-------------------------------------------------------------------------------
 Repo secrets: GEMINI_API_KEY, GROQ_API_KEY, SUPABASE_URL, SUPABASE_SERVICE_KEY.

 !! Do NOT pipe values into `gh secret set` from Windows PowerShell. PowerShell 5.1
 !! prefixes piped text with an invisible byte-order mark, and that is exactly what
 !! broke the cron from 2026-09-09 to 2026-09-15. Pass the value as an argument:

gh secret set SUPABASE_URL --body "https://<project-ref>.supabase.co"
gh secret set SUPABASE_SERVICE_KEY --body "<service_role key>"
gh secret set GEMINI_API_KEY --body "<key>"
gh secret set GROQ_API_KEY --body "<key>"

 (or paste them in GitHub > Settings > Secrets and variables > Actions.)
 The pipeline now strips such characters itself and `agent check` names any key
 it had to correct, but a clean secret is still the fix.

 Run it once by hand instead of waiting for 06:30 UTC:

gh workflow run daily.yml
gh run watch

-------------------------------------------------------------------------------
 4. THE SITE ON VERCEL  (free Hobby plan)
-------------------------------------------------------------------------------
 1. vercel.com > Add New > Project > import maurya-65/DevNews-AI.
 2. Root Directory: web      (Framework preset: Next.js, detected)
 3. Environment variables:
      NEXT_PUBLIC_SUPABASE_URL        same as SUPABASE_URL
      NEXT_PUBLIC_SUPABASE_ANON_KEY   Supabase > Project Settings > API Keys > anon
      SUPABASE_SERVICE_KEY            service_role key. Server-only: never NEXT_PUBLIC_
      NEXT_PUBLIC_AUTH_PROVIDERS      leave empty for email + password
 4. Deploy. Note the URL, e.g. https://devnews-ai.vercel.app
 5. Supabase > Authentication > URL Configuration:
      Site URL        https://<your-app>.vercel.app
      Redirect URLs   https://<your-app>.vercel.app/auth/callback
 6. Links in email and RSS point at the site:

gh variable set SITE_URL --body "https://<your-app>.vercel.app"

 Vercel builds on every push; the production branch is main.
